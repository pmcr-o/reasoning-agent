# routing

The 7 October 2026 report says a shipping router sends easy or common work to a lighter model and hard or unusual work to a stronger model, and that the route is validated on the domain before high-stakes use. The report publishes no numeric route cap. This contract sets `cap` to 1, one route decision, then stop. A missing cap exits non-zero. `default` stays `lightest`.

`scripts/validate.ps1` reads `assets/contract.json` only. It does not call the network, read an API key, or invoke a model.

Chain-of-thought, self-consistency, tree or graph search, Reflexion, least-to-most, debate, and mixture-of-agents are papers. They are not this skill.
